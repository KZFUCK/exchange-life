# 当前经营原型

Godot 主场景为 `scenes/operations.tscn`。办公室常驻，底部入口是新项目、员工、办公室、营业/暂停、速度和菜单。管理弹窗会暂停本周营业，返回后可显式继续。

创业公司可选择四人工位模板，再招聘与安排员工。办公室支持购买、摆放、移动和出售工位；销售回收价格为 ¥400，非法位置或取消操作保留原状态。

新项目选择产品与目标用户，支付预算后，由真实到岗工时推进企划、开发和测试；上线记录评价、销售、用户和口碑。已赚得的研发点可用于培训与产品解锁。

菜单支持保存、重载和恢复备份。恢复前需确认；损坏或不支持的存档会保护原文件。当前公司使用 `operations_v1.json` 存档，与早期数值原型存档分开。

当前规模为四/八/十二人。共享区尚无休息或维护行为，完整战役、角色阵容、丰富事件和最终画面仍待制作。Mac Metal 入口沿用原人物网格；GL Compatibility 入口按材质合并人物绘制，保留原骨骼与动作。
