# BD 研修操作

默认场景是 `scenes/mm_bd.tscn`。研修主页选择客户委托，通过问题了解需求，再在方案工坊输入报价与风险范围。必需访谈项是验收指标、资金安排和服务边界。

客户提出不合理承诺时，需解释真实流动性服务的交付指标。超出预算或覆盖不足的方案会回到工坊；保证价格、成交量和损失的回答不会进入交付。

交付观察台每个训练日需要选择处置建议，底部三个按钮固定可见。注意中间价、双边深度、试单滑点与库存；按勾选项决定是否向客户说明影响与恢复条件。

六日后进入带教复盘，可导出报告。保存、读取和恢复备份在右上角，读取与恢复需要确认，取消保留当前状态。关闭窗口会保存，重开会继续有效研修档；坏档受保护。

当前是虚构案例的培训首版，公司真实服务政策需由负责人核对。旧经营源码、模型和独立存档保留作为回退。
